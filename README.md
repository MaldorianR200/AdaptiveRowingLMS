# Adaptive Rowing LMS

Демонстрационная клиентская платформа дистанционного обучения по курсу «Теоретическая подготовка спортсменов в адаптивной академической гребле».

> Это учебный прототип, не реальная многопользовательская LMS. Регистрация, серверная авторизация и backend отсутствуют. Роли — демонстрационные; изменяемые данные остаются в localStorage конкретного браузера.

## Технологии

Angular 22, TypeScript strict, Standalone Components, Signals, Angular Router (hash location), Reactive Forms/Forms, SCSS, Vitest и GitHub Actions.

## Запуск

```bash
npm ci
npm start
```

Откройте URL, который напечатает Angular CLI (обычно `http://localhost:4200`). Production-сборка: `npm run build`.

## Демонстрационные профили

В верхней панели переключаются два спортсмена, тренер и ассистент. Данные каждого спортсмена независимы. Это переключение не является защитой данных.

## Учебный сценарий

1. Откройте курс и лекцию.
2. Явно отметьте изученными все четыре страницы.
3. Нажмите «Завершить лекцию» — тест станет доступен.
4. Выполните до двух попыток. За два из трёх правильных ответов в вопросе 2 без ошибочного начисляется 0,5; вопрос на соответствия оценивается пропорционально.
5. Тренер может просмотреть демонстрационные данные текущего браузера и сбросить профиль с подтверждением.

## Контент и ограничения

Тексты четырёх страниц лекции и вопросы внесены из предоставленного технического задания. Указанный в нём исходный файл `Системы_дистанционного_обучения.docx` отсутствовал в рабочем каталоге при разработке, поэтому независимая сверка и подтверждение полного переноса из DOCX не выполнялись. Видео явно помечено как «Видеоматериал в подготовке»; неработающего видеоплеера нет. Официальные спортивные нормативы не выдумывались. Видимые блоки схем — иллюстративные заглушки, а не реальные планы спортивных объектов.

## Публикация на GitHub Pages

В репозитории включите **Settings → Pages → Build and deployment → GitHub Actions**. Workflow `.github/workflows/deploy.yml` запускает линтер, тесты и production-сборку с base-href репозитория, затем публикует статические файлы. Angular использует hash-маршрутизацию для прямых ссылок и обновления страниц.

```bash
git init
git add .
git commit -m "Initial Adaptive Rowing LMS implementation"
git branch -M main
git remote add origin https://github.com/OWNER/REPOSITORY.git
git push -u origin main
```

Подставьте реальный адрес созданного GitHub-репозитория.
