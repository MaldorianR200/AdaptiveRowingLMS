# Adaptive Rowing LMS

**Учебная платформа по адаптивной академической гребле.** Помогает спортсменам изучать основы тренировок и безопасности в своём темпе, а тренеру и ассистенту — знакомиться с учебным маршрутом и демонстрационными данными.

[Открыть сайт](https://maldorianr200.github.io/AdaptiveRowingLMS/) · [Проверить публикацию](https://github.com/MaldorianR200/AdaptiveRowingLMS/actions/workflows/deploy.yml)

> [!NOTE]
> Это клиентский учебный прототип. Аккаунтов, серверной авторизации и синхронизации между устройствами нет. Имена, результаты и настройки сохраняются только в `localStorage` текущего браузера. Не вводите реальные чувствительные данные.

## Что есть в проекте

- **Быстрый старт:** имя, фамилия и выбор роли — спортсмен, тренер или ассистент.
- **Свободная навигация:** четыре темы доступны независимо друг от друга. Каждую из четырёх страниц подробной лекции по безопасности можно открыть напрямую и изучить в любом порядке.
- **Проверка знаний:** пять заданий, до двух попыток и частичное оценивание там, где оно предусмотрено материалом. Для открытия теста нужно отметить изученными четыре страницы лекции по безопасности.
- **Учебные материалы:** шаблон дневника самоконтроля и [видео адаптивной тренировки от British Rowing](https://www.youtube.com/watch?v=7SJ9RIqN_5Y). У видео есть прямая ссылка на случай, если встроенный плеер недоступен.
- **Демонстрационные роли:** персональный прогресс спортсменов, обзор для тренера и ассистента, форум и настройки отображения.
- **Доступность интерфейса:** управление с клавиатуры, настройки контраста, размера текста и уменьшения анимации. Соответствие WCAG не заявлено без отдельного аудита.

### Как устроен курс

| Тема                           | Содержание                                                                                         |
| ------------------------------ | -------------------------------------------------------------------------------------------------- |
| Основы тренировочного процесса | Структура занятия, постепенность нагрузки, восстановление                                          |
| Техника безопасности           | Четыре самостоятельные страницы лекции и итоговый тест                                             |
| Правила и нормативы            | Обзор правил и подготовки к старту; актуальные требования нужно сверять с официальными документами |
| Самоконтроль                   | Дневник занятий, субъективная нагрузка и самочувствие                                              |

Angular 22 · TypeScript · SCSS · Angular Router · Signals · Vitest · ESLint · Prettier · GitHub Actions/Pages.

```text

├── core/
│   ├── data/          # Материалы курса и вопросы
│   ├── state/         # Профили и прогресс в localStorage

```

## Локальный запуск

Нужны Node.js 22 и npm. Из корня проекта:

```bash
npm ci
npm start
```

Откройте адрес, который покажет Angular CLI (обычно `http://localhost:4200`). Проверки и сборка:

```bash
npm run lint
npm test -- --watch=false
npm run format:check
npm run build
```

Готовые статические файлы находятся в `dist/adaptive-rowing-lms/browser/`.

## Публикация на GitHub Pages

Репозиторий: [`MaldorianR200/AdaptiveRowingLMS`](https://github.com/MaldorianR200/AdaptiveRowingLMS). Workflow уже подготовлен: при каждом push в `main` он устанавливает зависимости, запускает линтер, тесты и проверку форматирования, собирает приложение и загружает его в GitHub Pages.

1. Откройте **Settings → Pages** в репозитории.
2. В **Build and deployment → Source** выберите **GitHub Actions**. Для бесплатного GitHub Pages репозиторий должен быть публичным.
3. Откройте вкладку **Actions** и дождитесь успешного запуска **Build and deploy to GitHub Pages**. При необходимости запустите workflow вручную через **Run workflow**.
4. Проверьте сайт: **https://maldorianr200.github.io/AdaptiveRowingLMS/**. Первый запуск и обновления могут появиться с задержкой в несколько минут.

Для следующих обновлений достаточно отправить изменения в `main`:

```bash
git add .
git commit -m "feat(course): добавить новую тему"
git push origin main
```

Для GitHub Pages сборка задаёт `base-href` по имени репозитория. В приложении используется hash-маршрутизация, поэтому ссылки на отдельные лекции работают и после обновления страницы. Если переименовать репозиторий, адрес сайта изменится; workflow подхватит новое имя при следующей сборке.

## Происхождение материалов и ограничения

Основой послужил документ [`docs/source/Системы_дистанционного_обучения.docx`](docs/source/Системы_дистанционного_обучения.docx). Подробная лекция по безопасности и пять заданий перенесены из исходного материала; остальные темы дополнены краткими пояснениями. В общем описании документа упоминаются шесть вопросов, но конкретный тест содержит пять, поэтому в приложении реализованы пять заданий.

Видео British Rowing показывает адаптивную тренировку **в помещении на тренажёре**. Оно не заменяет индивидуальный план тренера или инструктаж по безопасности на воде. Нормативы соревнований здесь не публикуются: сверяйте их с действующими правилами и положением конкретного старта.

Данные демонстрационных профилей доступны только в том браузере, где они были созданы. Смена роли не является механизмом защиты данных, а GitHub Pages предоставляет только статический хостинг без backend.
