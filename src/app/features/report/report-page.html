Отчёт по разработке Adaptive Rowing LMS

Цель

Создание демонстрационной образовательной платформы для дистанционной теоретической подготовки спортсменов в адаптивной академической гребле.

  1. {{ t.title }}. {{ t.outcome }}

Роли

Тренер просматривает локальные результаты и видимость разделов; спортсмен изучает лекцию и выполняет тест; ассистент просматривает материалы и требования доступности. Переключение не является авторизацией.

Оценивание

Пять заданий, максимум 5 баллов, зачёт от 4 баллов. В вопросе с множественным выбором применяется частичная оценка 0,5; за соответствие начисляется пропорциональная доля балла. Допускаются две попытки, учитывается лучший результат.

Архитектура и ограничения

Angular SPA, TypeScript, SCSS, Angular Router с hash-навигацией и localStorage. Backend отсутствует. Локальные данные доступны только в текущем браузере. Тексты лекции и вопросы сверены с docs/source/Системы_дистанционного_обучения.docx; текстовый экспорт с таблицами сохранён рядом. В исходном документе видео и иллюстрации обозначены как планируемые, поэтому приложение показывает честный статус подготовки. Официальные нормативы не выдуманы.

Доступность и статус материалов

Реализованы базовые клавиатурные элементы, подписи, альтернативные описания, переключатели крупного текста и контраста. Фактическое соответствие WCAG требует отдельного тестирования. Статус чек-листа хранится локально.

Заключение

Создана клиентская демонстрация учебного сценария. Она не является настоящей многопользовательской LMS и не обеспечивает синхронизацию результатов. Публичная ссылка будет добавлена после публикации репозитория на GitHub Pages.
